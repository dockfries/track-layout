赛道 JSON 格式

工具只需要一个有序的检查点数组。每个点必填 x、y，z 可选；顺序即赛道顺序，首点为起点、末点为终点（闭环时首点为起终点）。

{
  "name": "Los Santos Loop",
  "author": "your name",
  "closed": false,
  "checkpoints": [
    { "x": 2287.4, "y": -1605.9, "z": 2.6 },
    { "x": 1617.6, "y": -1205.8, "z": 51.8 },
    { "x": 1599.0, "y": -2378.2, "z": 12.4 }
  ]
}

兼容写法

  • 顶层直接放数组：[{ "x": 0, "y": 0 }, ...]
  • 数组键名可用 checkpoints、cps、points、cp、waypoints。
  • 点位可用 [x, y, z]、{ "pos": [x, y, z] }、{ "position": { "x": … } }。
  • type 可写 start / cp / finish，但最终角色由顺序决定。
  • 可选字段：label（显示名称）、radius（保留字段）。

坐标系

GTA San Andreas：x 向东，y 向北，z 向上，地图范围约 −3000…3000。路网寻路使用 SA 的车辆节点；自定义底图只改变显示，不改变坐标系。

路网计算

每个 CP 会吸附到最近的车辆道路节点（默认 80 m），然后用 A* 逐段寻路；找不到路网时按设置回退到平滑曲线或直线，并在「路线」页列出原因。
