# Icons

Lucide icon geometry was fetched from the [Iconify API](https://api.iconify.design/)
on 2026-10-31 and bundled into `sprite.svg` so the app stays offline-friendly.

- Collection: [Lucide](https://lucide.dev/)
- License: ISC (see `LICENSE`, copied from the upstream Lucide repository)
- Sprite form: `<symbol id="i-...">` referenced with `<use href="assets/icons/sprite.svg#i-...">`

Do not edit individual symbols by hand; replace the sprite with a fresh export if
the icon set changes.
